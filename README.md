# Pentavox Studio

Configuration app for the Pentavox module (Alchemy Lab, STM32H750): engines, CV and MIDI routing, knob record, settings, presets, sampler, DX7 banks.

Open it: **https://vaniastarginsky-commits.github.io/pentavox-studio/**

Chrome or Edge is needed (Web Serial for the module, WebUSB for flashing).

## What works where

- Connecting to the module, editing, presets: in the browser, over Web Serial. Nothing else is needed.
- **Build** and **Flash** have two modes:
  1. **Build server on your computer** (`tools/engine_composer/serve.py` of the private firmware repository). The page talks to it at
     `http://127.0.0.1:8766` (or the next free port) and sends the token from `~/.pentavox-build/api-token`. Build and flash run there.
  2. **No server: the cloud.** Build runs as a GitHub Actions workflow of the firmware repository and the image is flashed from the browser
     over WebUSB DFU. It needs a GitHub token in this browser (fine-grained, Actions: write and Contents: read on the firmware repository);
     the page asks for it at the first Build and keeps it in `localStorage`. After **Reboot to DFU** press **Flash** and choose the DFU device.

The page picks the server when it answers and the cloud otherwise.

This repository is generated by `tools/publish_studio.sh` in the firmware repository; do not edit it by hand.
