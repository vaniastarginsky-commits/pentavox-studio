# Pentavox Studio

Configuration app for the Pentavox module (Alchemy Lab, STM32H750): engines, CV and MIDI routing, knob record, settings, presets, sampler, DX7 banks.

Open it: **https://vaniastarginsky-commits.github.io/pentavox-studio/**

Chrome or Edge is needed (Web Serial, and WebUSB for flashing).

## What works where

- Connecting to the module, editing, presets: in the browser, over Web Serial.
- Build and Flash use the build server `tools/engine_composer/serve.py` of the (private) firmware repository, running on your own computer. This page talks to it at `http://127.0.0.1:8766` and sends the token from `~/.pentavox-build/api-token`.

This repository is generated by `tools/publish_studio.sh` in the firmware repository; do not edit it by hand.
