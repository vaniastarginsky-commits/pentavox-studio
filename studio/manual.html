Using Studio

Studio is the module's settings window in a browser. Everything you change is heard on the module at once; Save to slot makes it permanent.

In two minutes

  1. Use Chrome or Edge on a computer. Connecting needs Web Serial and flashing needs WebUSB; Safari, Firefox and phones have neither. There you can still press Demo and explore every tab on a simulated module.
  2. Plug the USB-C cable into the front panel and close any other programmer: the port serves one program at a time.
  3. Press Connect and choose the module in the browser's list. The dot in the header turns green and shows the module name and firmware version.
  4. Change something. Not saved appears: the module plays the change, but power-cycling forgets it. Save to slot keeps it, Discard changes goes back to the stored sound.

The tabs

Sampler
Drop in audio (wav, mp3, flac, ogg, aiff), trim and normalize it, pick slot 1–4 and download pentavox_samples.zip. Copy its SLOT0…SLOT3 folders to the SD card (FAT32), merging with what is there. You can cut a sample into up to 32 slices and build break patterns on them; the slice map and patterns are saved inside the WAV.
Engines
Each voice has 24 engines: three banks of eight, picked from a library of 94 on the right. Drag an engine from the library into a slot to put it there (slots can be dragged to swap places); the play button previews an engine in the browser. With a module connected, clicking a slot makes the selected voice play that engine. Stereo, Sync In and the DX7 bank are slot properties applied at build time. The meter at the bottom estimates how much code memory the set needs: when it runs red, Build is disabled and Suggest replacements lists lighter engines from the same category. A new set only takes effect after Build and Flash (see below).
CV routing
For each jack J3–J8, each panel knob and the expander, up to four parameters with a depth from −100 to +100 %. J3–J8 can also carry one built-in function (none, FX freeze, Phaser CV, Bar reset or Clock input); assigning a function to a jack clears it from the jack that had it. The Notes part sets each voice's MIDI channel and its pitch and gate sources.
MIDI routing
One table for the module: a row listens to a controller (or note velocity) on a channel and adds its value times the depth to a parameter. A negative depth inverts; several rows may drive one parameter.
Knob record
Shows the loops recorded with B3 + knob, one per knob and page. Open a loop to edit it as a curve, start a new curve, or load a ready-made one. Changes apply to the playing module at once. Erase on the module with B1 + B3 and a knob (hold the chord to erase all).
Settings
The same list as the module's own Settings page (hold B2 + B3): input level, LED brightness, clock PPQ and tempo multiplier, voice mode (separate, poly, unison), sampler choke, record threshold and the sample library of each slot.
Presets
Load a stored sound set into the module or save the current one. Slot 1 is the autosave: the module writes it by itself and starts from it. Names are kept in this browser. Export backup downloads every slot as one file; Import backup writes them back.

Flashing new firmware

Choosing different engines changes the firmware itself, so they take effect only after a build and a flash. You need Chrome or Edge on a computer.

  1. Back up your presets. In Presets, press Export backup. A new firmware can change the preset layout, and then every stored preset is reset. Studio asks about this before flashing.
  2. Engines → Build. On the hosted Studio the firmware is built in the cloud with GitHub Actions. That needs a GitHub token (fine-grained, with Actions: write and Contents: read on the firmware repository); Studio asks for it once and keeps it in this browser only. Run from your own computer with ./studio/serve.sh, Build runs locally instead.
  3. Put the module in DFU mode: press Reboot to DFU while connected, or hold B3 while switching the module on.
  4. Press Flash and choose the DFU device in the browser's list. Wait until it says it has finished; the module restarts by itself.
  5. Press Reconnect. If a new firmware version came with changed presets, restore the backup from Presets.

If a flash is interrupted, put the module in DFU mode again and flash again.

Troubleshooting

“Port busy”
Another program holds the serial port. Close the official programmer and any other Studio tab, then press Reconnect.
The module does not show up
Check that the cable carries data (not only power) and that you use Chrome or Edge. In DFU mode the module is a different USB device and does not appear as a Studio connection.
A knob does nothing after changing page
The module catches each knob's stored value after a page change: turn the knob until it reaches the value on that page, then it takes over.
The module is silent
Each voice plays from MIDI (set its channel in CV routing → Notes) or from CV pitch and gate sources you assign there. With neither, there is nothing to play it.
My changes are gone after a restart
They were never saved: press Save to slot while Not saved is shown. Slot 1 in Presets is the autosave the module starts from.
Studio looks out of date after an update
Reload the page. If an old version still shows, close the tab and open it again.
