# Factory previews

`factory.json` is generated by `tools/palette/export_wave_previews.py` from
the pinned Mutable Instruments Plaits source. These approximate previews are
for editing/audition only; factory firmware data remains unchanged.

# iNit-Crioxica surfaces

`init-crioxica.json` preserves three sampled surfaces from
https://archive.org/details/i-nit-crioxica-plaits-firmware . Credit: iNit-Crioxica.
The archive uploader marks the item Public Domain Mark1.0; embedded resource
metadata says Local. Original formulas and sample bytes are retained.
